# PORTIVA Website

A static, responsive PORTIVA landing page.

## Deploy free
- GitHub Pages: create a repository, upload `index.html`, then enable Pages from the repository Settings.
- Cloudflare Pages: connect the repository and deploy with no build command.

## Before launch
Replace the placeholder Discord and X links in `index.html` with PORTIVA's official community URLs.
Add the official token contract address only after deployment and verification.
